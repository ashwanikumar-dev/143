# Audio Assets Guide

This directory holds the sound effects and background music for "A Little Step Forward".

## Expected Audio Files

| Filename | Purpose | Recommended Tone |
| :--- | :--- | :--- |
| `music.mp3` | Main ambient background music | Gentle acoustic guitar, soft piano, or lo-fi romantic instrumental (looping). |
| `sfx-envelope-open.mp3` | Wax seal cracking / letter opening | Soft paper rustle or wax break. |
| `sfx-wheel-tick.mp3` | Love wheel spinning segment crossing | Light wooden or mechanical soft click. |
| `sfx-heart-pop.mp3` | Catching falling hearts in Chapter 8 | Cute, bubbly pop sound. |
| `sfx-card-flip.mp3` | Flipping sweet notes in Chapter 6 | Crisp paper card shuffle or turn. |
| `sfx-correct.mp3` | Quiz correct answer | Sweet chime or positive melodic note. |
| `sfx-wrong.mp3` | Quiz non-matching answer | Gentle whimsical wobble (never harsh). |
| `sfx-win.mp3` | Game win / Celebration | Soft celebratory sparkle chime. |
| `sfx-transition.mp3` | Chapter transition whoosh | Very subtle soft breeze or air whoosh. |
| `sfx-secret-heart.mp3` | Secret heart discovery chime | Dreamy music box or harp flourish. |
| `sfx-chime.mp3` | General pleasant notification chime | Warm chime. |

## Licensing & Sources

- Recommended royalty-free sources:
  - **Pixabay Audio** (free for personal use, high quality)
  - **Freesound.org** (Creative Commons 0)
  - **Free Music Archive**
- Please ensure you own or have permission for any audio files you place here.
- If an audio file is missing, the application automatically and silently skips it without any errors or interruptions.
