# Photos Directory Guide

This folder holds images for Chapter 7: Memory Lane (Polaroids and Timeline).

## Recommended Specs

- **Formats**: `.webp`, `.png`, or `.jpg` (`.webp` is recommended for fastest load times)
- **Polaroid Photos**: `photo1.webp`, `photo2.webp`, etc.
  - Recommended dimensions: 600×600 or 800×800 square
  - Keep under 250KB per photo for smooth mobile loading
- **Graceful Fallbacks**:
  - If a photo has not been added yet, the site automatically displays a warm, elegant pastel gradient placeholder with soft floral watermark so the experience never looks broken.
